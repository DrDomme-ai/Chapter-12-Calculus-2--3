# Interactive Calculus

A React and Vite learning environment for Dr. Domme's Calculus II and Calculus III students. The application combines visual explanations, guided instruction, interactive exploration, and prerequisite practice.

## Local development

```bash
npm install
npm run dev
```

Vite prints the local address after the development server starts.

## Quality checks

```bash
npm run lint
npm run build
```

The shared Chapter 12 material and review components live under `src/lectures`, `src/reviews`, `src/components`, and `src/data`.
